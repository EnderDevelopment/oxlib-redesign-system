# OxLib Redesign System

Enhance your FiveM server with customizable OxLib redesign options.

## Features

- Customizable OxLib interface with multiple redesign options
- Player-specific redesign preferences saved to a database

## Requirements

- FiveM server
- ESX framework
- ox_lib
- oxmysql

## Installation

1. Download the script from the [releases page](https://github.com/EnderDevelopment/oxlib-redesign-system/releases).
2. Extract the files into your FiveM server's `resources` directory.
3. Add `start oxlib-redesign-system` to your server.cfg file.
4. Import the `database.sql` file into your database.

## Usage

- Players can open the redesign menu by typing `/redesign` in the chat.
- Select a redesign option from the menu to apply it to their OxLib interface.

## Configuration

The script can be configured in the `config.lua` file. You can adjust the database settings and enable debug mode if needed.
